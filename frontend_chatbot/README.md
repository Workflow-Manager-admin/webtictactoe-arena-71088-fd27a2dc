# KAVIA Demo AI Chatbot Frontend

A minimal, modern, independent React SPA for chatting with an AI assistant.

## Features

- **Modern UI**: Minimalistic, light-theme, and responsive
- **Color Palette**: Uses #007bff (primary), #6c757d (secondary), #28a745 (accent)
- **Clean code**: No UI frameworks; just React and custom CSS
- **Fully Independent**: Not connected to or dependent on `frontend_app` or any games logic.

## Usage

Install dependencies and start dev server:
```
npm install
npm start
```
Serves at [http://localhost:3000](http://localhost:3000) (or next free port).

## Folder structure

- `src/App.js`    Main chatbot container
- `src/App.css`   Component and theme styles
- `src/index.js`  Entrypoint
- `src/index.css` App-level (reset/global) CSS
